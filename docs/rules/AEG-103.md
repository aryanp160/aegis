# AEG-103: Unsafe NOT NULL column addition

**Category:** Destructive
**Severity:** ERROR
**Risk:** Can cause migration failures or app errors if the table contains existing rows, as new columns default to NULL.

## Problem

Adding a NOT NULL column to an existing table without a default value fails if rows exist.

## Why it is dangerous

Adding a NOT NULL column to an existing table requires all existing rows to satisfy the NOT NULL constraint. If no default value is defined, the database will attempt to fill existing rows with NULL, violating the constraint.

## Unsafe SQL

```sql
ALTER TABLE users ADD COLUMN age INT NOT NULL;
```

## Safe SQL

```sql
ALTER TABLE users ADD COLUMN age INT NOT NULL DEFAULT 0;
```

## Remediation

Provide a DEFAULT value when adding a NOT NULL column, or add the column as nullable first.
