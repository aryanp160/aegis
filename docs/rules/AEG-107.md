# AEG-107: DROP TABLE / DROP COLUMN protection

**Category:** Destructive
**Severity:** ERROR
**Risk:** High risk of losing production data or causing runtime errors.

## Problem

Protects against destructive drops of tables or columns.

## Why it is dangerous

Dropping tables or columns deletes schema structures. The operation is disallowed unless overridden with the '-- aegis:allow-destructive' directive.

## Unsafe SQL

```sql
DROP TABLE users;
```

## Safe SQL

```sql
-- aegis:allow-destructive
DROP TABLE users;
```

## Remediation

To run, verify safety, back up data, and add the override directive '-- aegis:allow-destructive' comment.
