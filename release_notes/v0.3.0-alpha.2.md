# Aegis v0.3.0-alpha.2 Release Notes

We are excited to release **Aegis v0.3.0-alpha.2**! This release focuses on rule suppression and configuration, rich terminal diagnostics, expanded PostgreSQL rule coverage, a golden regression test suite, and performance optimizations.

## What's New

### 1. Rule Suppression & Configuration (`aegis.toml`)
You can now define an `aegis.toml` configuration file (or use a `[tool.aegis]` table inside `pyproject.toml`) to control rules dynamically:
- **Global Ignores:** Disable specific rules via `ignore_rules = ["AEG-XXX"]`.
- **Per-Rule Customization:** Change default rule severity or enable/disable states under `[rules."AEG-XXX"]`.
- **Per-File Glob Suppression:** Disable specific rules on selective files or directory glob patterns under the `[suppressions]` table.

### 2. Rich Terminal Diagnostics
Violations now yield visual diagnostics when rendered in the terminal:
- Identifies the exact rule ID, title, severity, category, file, line, and column.
- Extracts the exact compiled SQL statement snippet violating safety boundaries.
- Produces highlighted caret indicators pointing directly to the offending column offset.

### 3. Expanded PostgreSQL Safety Rules
Improved static analysis coverage for Postgres migrations:
- **AEG-103 (Unsafe NOT NULL column addition):** Now detects `ALTER COLUMN SET NOT NULL` updates on existing columns.
- **AEG-105 (Foreign keys without NOT VALID):** Now detects inline column reference constraints (`ADD COLUMN ... REFERENCES ...`). Added AST check constraint traversal deduplication to prevent double-reporting.
- **AEG-106 (CONCURRENTLY inside transaction):** Added parser support for `exp.Rollback` statements.

### 4. Golden SQL Test Suite
Introduced a Golden SQL testing framework to prevent rules regressions. The engine evaluates a comprehensive, unsafe migration file (`input_unsafe.sql`) and asserts that the serialized outputs match expectations (`expected_output.json`) exactly.

### 5. Caching & Performance Optimizations
- **AST Visitor Caching:** Caches pre-bound method routing lookups by node class to speed up tree traversal.
- **Visitor Relocation:** Moved visitor classes to the module level to reduce Python class allocation overhead.
- **Registry & Engine Caching:** Caches registry lookup lists and post-processing string splits.
- **Benchmark Results:** Achieved a **~10% reduction in execution latency** (down to 1.303s on a 1,000-migration workload).

## What's Next in v0.4.0-beta.1
In the next release milestone, Aegis will transition from library APIs to its first production-ready command line interface. We will implement:
- `aegis lint` to run rule analysis directly on target folders and files.
- `aegis explain <RULE-ID>` to render safety information, problem definitions, safe/unsafe SQL examples, and remediation steps.
- Rich-based terminal formatting with vibrant colors, syntax highlighting, and progress bars.
