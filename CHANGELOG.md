# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0-alpha.1] - 2026-07-04

### Added
- Bootstrap repository structure: `docs/`, `examples/`, `benchmarks/`, `scripts/`.
- Development configurations: `.gitignore`, `.editorconfig`, `.pre-commit-config.yaml`.
- Core python package configurations in `pyproject.toml`.
- Typer CLI with `aegis --help` and `aegis version`.
- Pydantic configuration loader skeleton.
- Rich-based logger configuration.
- Pytest test cases for CLI and configuration.
- CI pipeline workflow via GitHub Actions.
- Documentation: `README.md`, `CONTRIBUTING.md`, `SECURITY.md`, `CODE_OF_CONDUCT.md`.
